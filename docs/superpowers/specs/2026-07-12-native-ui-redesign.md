## 확정 요구사항

1. **WE = 구조 레퍼런스**: 탭 3개(설치됨/검색/창작마당)·검색/필터/정렬·접이식 필터 사이드바·그리드·우측 상세 패널·하단 바라는
   **배치와 UX 흐름**만 따른다. 색·컨트롤·아이콘·치수를 WE에 맞추지 않는다(스포이드·실측·좌우 픽셀 비교 폐기).
2. **시각 = 네이티브 SwiftUI/macOS(HIG)**: 시스템 컨트롤(`bordered`/`borderedProminent`·세그먼트·네이티브 서치필드·Picker·Toggle·Slider),
   SF Symbols, 시스템 타이포 스케일. **커스텀 hex 색 금지** — 시맨틱 컬러와 시스템 재질만.
3. **항상 다크**: 창 단위 `darkAqua` 강제 유지. 다크 하의 시맨틱 값만 사용(라이트 대응 없음).
4. **콘텐츠가 주인공**: 크롬은 조용한 무대. 그리드 우물 = `underPageBackgroundColor`(한 단 깊게), 바 영역 = 시스템 재질,
   액센트 = 시스템 `accentColor`. 색·개성은 썸네일/라이브 프리뷰가 담당.
5. **시그니처 1개 — Now Playing 바**: 하단을 WE식 버튼 나열 대신 Music.app식 재생 바로.
   현재 적용 배경의 애니 썸네일+제목 상시 표시, 일시정지/다음/재생목록 컨트롤. "Waple = 월페이퍼 플레이어" 정체성.
   나머지 표면은 절제된 HIG — 커스텀은 타일과 이 바 둘뿐.
6. **완료 기준**: 표면별 스크린샷 → 사용자 "보기 좋고 네이티브답다" 판정. 기존 테스트 그린 유지.
7. **기능 범위는 클론 스펙 그대로 승계**: 백엔드 확장(즐겨찾기·태그/등급 필터·평점 표시·라이브러리 제거·폴더·디스커버 쿼리)과
   기능 매핑 표(모바일/에디터/투표/코멘트/신고 = 비활성+툴팁, 구독 취소 = 제거 매핑 등) 전부 유지. 페이지네이션만 폐기(네이티브 스크롤).

## 레이아웃 (WE 구조의 네이티브 번역)

```
┌─ 네이티브 통합 툴바 ─────────────────────────────────┐
│ ●●●  [설치됨|검색|창작마당](세그먼트)   🔍 ⛛필터 정렬⌄ ⌸ │
├────────┬────────────────────────────────┬───────────┤
│ 필터    │  썸네일 그리드(스크롤)           │ 상세 패널   │
│ 사이드바 │  호버=라이브 프리뷰·리프트        │ 히어로 프리뷰│
│ (SP2′)  │  적용 중=액센트 링              │ 메타·속성   │
│         │  underPageBackground 우물      │ 액션 버튼   │
├────────┴────────────────────────────────┴───────────┤
│ [▶애니 썸네일] 현재 배경 제목   ⏯ ⏭ | 재생목록⌄  + 열기 │  ← Now Playing 바(시그니처)
└──────────────────────────────────────────────────────┘
```

- 툴바: 네이티브 NSToolbar(unified) — 세그먼트 탭(leading), 검색·필터 토글·정렬 메뉴·패널 토글(trailing).
  모바일/디스플레이/설정은 툴바 아이콘 버튼(모바일·설정은 비활성+툴팁, 디스플레이는 시트 — SP3′에서 화면 승격).
- 타일: 라운드 썸네일 + **제목은 아래**(Photos/Finder 관례, WE 오버레이 아님), 타입 배지 SF Symbol,
  적용 중 = accentColor 링 + 재생 인디케이터, 호버 = 라이브 프리뷰 + 미세 리프트, 미지원 = 감광+배지.
- 상세 패널: 고정폭, 히어로 프리뷰(상시 애니) → 제목/타입/메타 → 액션(`borderedProminent` 적용, 모니터별 메뉴,
  재생목록 토글, 제거) → 속성 편집(기존 PropertyEditorView 임베드, 그룹 폼 스타일). 툴바 ⌸ 버튼으로 접기.
- 상태 배너: 유지(모델 무변경), 시각은 시스템 재질 + 시맨틱 색으로 재스타일.
