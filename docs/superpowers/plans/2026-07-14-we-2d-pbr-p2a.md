# WE 2D Point-Light PBR (P2a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the reachable orthographic 2D point-light Lambert term with the source-confirmed `genericimage4` Cook–Torrance BRDF, including authored scalar PBR material constants and a documented zero-roughness safety guard.

**Architecture:** Parse `roughness`, `metallic`, and `speculartint` into `SceneLayer`, mirror the confirmed BRDF in a focused Swift CPU oracle, transport a fixed two-`float4` material payload through `GPULayer`, and consume it from `QuadShaders.f_lit` at fragment buffer `5`. Preserve the existing four-light payload, flat ambient composition, finite-light exponent attenuation, and orthographic `N = V = +Z` assumptions.

**Tech Stack:** Swift 6, XCTest, Metal Shading Language, Swift Package Manager.

## Global Constraints

- Implement only P2a's reachable orthographic finite-point lane. Do not add spot/directional formulas, tube lights, perspective billboards, 3D mesh lighting, shadows, normal/PBR masks, emissive, SSR, cookies, or native HDR/tone-map policy.
- Parse only `passes[0].constantshadervalues` and use native defaults `roughness = 0.7`, `metallic = 0`, `specularTint = white` when values are absent or invalid.
- Preserve raw finite authored values without authoring-range clamps; corpus-observed `roughness = 5` must survive parsing and transport.
- Use the confirmed `genericimage4` Cook–Torrance equations: GGX `alpha = roughness²`, Smith-Schlick `k = (roughness + 1)² / 8`, Fresnel-Schlick `F0 = mix(0.04, albedo, metallic)`, `kD = (1 - metallic) * (1 - F)`, and Lambert diffuse `kD * albedo / pi`.
- Apply `specularTint` only to the specular term. Do not multiply the completed direct term by albedo again.
- Preserve `N = (0, 0, 1)` and `V = (0, 0, 1)` for this orthographic slice.
- Preserve first-four scene-order selection, `color * intensity`, `radius <= 0`, `distance < 1e-5`, and the P1 hard-zero exponent falloff exactly.
- Preserve authored roughness at `0`; floor only the intermediate GGX distribution denominator at `1e-4` in Swift and Metal. Label this `[safety deviation]` in code comments.
- Return zero before constructing `H = normalize(V + L)` when `NL == 0`; this avoids a back-facing `normalize(0)` NaN without changing the selected path's defined zero result.
- Introduce every behavior test-first and observe the intended RED before production edits.
- Run only `SceneForwardLightingTests`, the PBR shader contract, the metallic material render test, and the existing spatial rendered-light smoke. Do not run the full Swift suite or real render corpus.
- Perform exactly one whole-branch code review after all implementation. Do not review each task separately.
- Preserve the user-owned `.vscode/launch.json` modification and never stage it.
- Commit messages must not contain an AI watermark.
